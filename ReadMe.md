# 🏥 증상 기반 진료과 추천 & 주변 병원 찾기 플랫폼

> **"이럴 땐 무슨 과에 가야 하지?"**  
> 증상을 기반으로 적절한 진료과를 추천하고 주변 병원을 연결하는 스마트 헬스케어 웹 프로젝트

---

## 📌 About Project

본 프로젝트는 의료 지식이 부족한 사용자가 낯선 증상 앞에서 **어떤 진료과를 방문해야 하는지 빠르게 판단할 수 있도록 설계된 서비스형 웹 플랫폼**입니다.

사용자가 일상 언어로 증상을 입력하면 적절한 진료과를 추천하고, 위치 기반 병원 탐색 기능을 통해 주변 의료기관까지 연결하는 UX를 구현했습니다.

또한 본 프로젝트는 **비개발자 기획자가 AI 협업(Vibe Coding)을 활용하여 기획 → 로직 설계 → 퍼블리싱 → GitHub Pages 배포까지 직접 수행한 프로젝트**입니다.
